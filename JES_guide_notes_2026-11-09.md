# Journal of Energy Storage: what the Guide for Authors means for ThermalStorageBench (read 9 November 2026)

Source: the journal's Guide for Authors on ScienceDirect, read 9 November 2026 (paraphrased here). The
journal page then showed Impact Factor 10.7 and CiteScore 16.6.

## Constraints that shape the paper

| Item | Rule | Consequence for us |
|---|---|---|
| Article type | Full length research article: ideally at most 6,000 words and 8 to 10 figures and/or tables | Main text must be tight. The 10 main figures in `FIGURE_INVENTORY_2026-11-08.md` plus tables exceed this; aim for about 7 figures + 3 tables in total |
| Supplementary material | Replication procedures and extra results such as sensitivity analyses go in an **Appendix**, not Supplementary Material. Supplementary is for videos, animations, interactive files | Everything planned as "supporting information" (verification detail, σ slope, WARN sensitivity, cross-GPU audit, multi-node detail) becomes Appendices A, B, ... (Fig. A.1, Table A.1, Eq. (A.1)) |
| Scope | Storage must be the central scientific contribution; optimisation techniques are not novelty and should not be highlighted in the title | Fits: the dataset and benchmark are about storage. Keep model names out of the title |
| Abstract | At most 250 words, no references, define abbreviations | |
| Keywords | 1 to 7 | |
| Highlights | 3 to 5 bullets, each at most 85 characters with spaces, separate file | |
| Graphical abstract | Encouraged, at least 1328 px wide, readable at 13 cm | Make one (both families, splits, headline result) |
| Research data | Option C: deposit data in a repository and cite/link it in the article, or explain why not | Zenodo (or similar) deposit with a DOI is needed **before submission**, so licence and hosting must be decided first |
| Data in Brief | Optional co-submission describing the data (separate APC) | Possible later; not needed |
| File format | Word single-column, or LaTeX | |
| References | Numbered in square brackets in order of appearance; any consistent style; DOIs where available; every reference must be real | Verify every reference and DOI (standing rule) |
| CRediT | Required from the corresponding author | |
| Funding | Statement required (or the "no specific grant" sentence) | |
| Generative AI | Use of AI tools in preparing the manuscript must be declared in a section before the references; authors remain responsible; AI must not be an author | **A declaration is needed for this paper** (wording to agree with all authors) |
| Competing interests | Declarations tool, uploaded as .docx | |
| Review | Single anonymised (reviewers see the authors) | No anonymised manuscript needed |
| Corresponding author | Only the corresponding author's affiliation decides publishing-agreement eligibility (open access discounts) | Saxam (KU): subscription, no fee. Henrik (Lund): possibly free OA via Bibsam |
| Authorship changes | Generally not considered after submission; none after acceptance | **Settle the author list before submission** (including whether Martin is on it) |
| Resubmission | A rejected paper cannot be resubmitted unless the Editor-in-Chief invites it | Only one attempt; submit when complete |
| Preprint | Allowed (optional free SSRN posting at submission; needs all co-authors' approval) | Decide with co-authors; an arXiv preprint would also be allowed |
